# Visual Lab / FIRE Shell Lab

This directory is the experimental shell environment for FIRE.

## Current mode: control baseline

Before redesigning the shell, this directory mirrors the observable G7 shell closely enough that physical review is comparing FIRE against FIRE—not FIRE against a simplified mini-app.

State is isolated under `babel-lab-fire-shell-v1`. Do not read/write FIRE production or G7 preview storage.

Read `BASELINE.md` and `PARITY_CHECKLIST.md` before visual changes.

## After parity

Create deliberate visual candidates from this baseline. Keep the normal product canvas free of permanent Lab-only navigation/explanation. Developer controls may be added behind an explicit Lab boundary.

Approved decisions return to `babel-fire` for canonical implementation and real-product validation. This directory never becomes FIRE authority.
