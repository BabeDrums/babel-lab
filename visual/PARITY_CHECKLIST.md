# FIRE Shell Lab — Physical Parity Checklist

Do this before visual redesign.

## iPhone first

- Projects list opens projects
- New Project opens and saves
- project `•••` opens management
- edit project saves
- delete project works against Lab state only
- project Home routes to Setup / Structure / Tracks
- Back returns through expected shell hierarchy
- Setup toggles work
- Tempo keyboard/input works without strange focus chrome
- Meter selection works
- Structure `+` opens adaptive bottom sheet
- Section presets work
- custom Section `+` reveals/focuses input
- custom Length `+` reveals/focuses numeric input
- section edit works
- reorder control changes order
- Accurate completion works
- Tracks selection works
- Add Track works
- Done confirms and returns Home

## iPad / wide

Repeat the same behavior checks and verify sheets become centered dialogs without changing semantics/action hierarchy.

## Pass condition

Do not begin candidate shell styling until missing/dead behavior or invented Lab chrome is no longer contaminating comparison. Small implementation differences are acceptable only when they are invisible to the shell question being tested.
