# Babel Lab

Experimental sandbox for Babel ecosystem concepts, interaction prototypes, and visual systems.

## Prototype 01 — World Object Grammar

This prototype is intentionally isolated from `BabeDrums/babel-fire`. It does not read or write FIRE runtime data, schemas, storage, or product code.

### What it tests

- World-style collection/home as a testing container, not a committed final Babel World form
- Source/origin marks as compact provenance markers that can also be inspected more deeply
- Achievement badges as meaningful accomplishments with inspectable evidence
- Skills/domains as capabilities, distinct from achievements
- A procedural personal Fire generated from particles rather than a static image
- A compact 2D pixel representation of the same Fire concept
- The interaction loop: see → recognize → tap → understand quickly → inspect deeper → follow evidence/provenance

### Run

Open `index.html` in a modern browser. No build step or dependencies are required.

### Important boundaries

- Fake prototype data only.
- Temporary Fire controls are visual probes, not the final evidence-to-visual mapping.
- No global Babel XP/level is implied.
- Fire does not grow from taps, streaks, elapsed days, or page completion.
- Generated image mockups from brainstorming are inspiration only, not product truth.
- This repository is a lab. Mature decisions still belong in the appropriate Babel/FIRE authority docs, not here by default.
