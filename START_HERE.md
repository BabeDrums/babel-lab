## Current prototype

### Prototype 02 — Fire + Achievements

The current experiment intentionally narrows the visible World-like surface to two ecosystem objects:

- **Fire** — a generated personal artifact driven by fake/simulated state for visual experimentation
- **Achievements** — one collection containing normal and hidden/lore achievements

Current prototype hypotheses/boundaries:

- simplified surface with Fire + Achievements only
- achievements can be manually earned/locked through developer controls
- hidden/lore achievements remain inside the same achievement collection
- FIRE source marks are supporting provenance UI, not a separate navigation system
- Fire uses flat 2D particles; no fake light emission / gradient plume requirement
- particle style can vary for visual testing
- emission is time-based so lower frame rates do not change density
- free-particle and rigid-grid views share the same underlying simulation logic
- rigid-grid remains animated
- all prototype state is fake
- `Evolve` is a simulation control, not approved progression
- achievement earning logic is intentionally not implemented
- no global Babel XP/level is implied

## Current product boundary

Babel Lab is a **workshop**, not Babel World.

A Babel World prototype may live here. A future real Babel World product earns its own repo once the job and implementation are real enough to justify it.

Likewise, exploratory FIRE concepts may be prototyped here, but real FIRE successor/product implementation with real FIRE semantics/data/regression concerns belongs in `BabeDrums/babel-fire`.

## Truth reconciliation rule

Do not blindly restyle/overwrite this prototype just because Babel Truth exists.

When asked to reconcile Lab with Truth:

1. read the pinned Truth authority
2. inspect current prototype decisions/code
3. identify every meaningful conflict
4. classify each as:
   - stale divergence
   - intentional experiment
   - potential upstream improvement
   - app/product-local exception
5. surface potential upstream improvements to Babel before changing either side
6. only then update stale divergence while preserving explicit experiments

The goal is for Lab to inherit good defaults **and** remain capable of discovering something better.
